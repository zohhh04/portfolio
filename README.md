# Zeba Fathima — Portfolio

## About this project
A personal portfolio website for Zeba Fathima, a full-stack developer (MERN × AI) based in Hyderabad, India. It presents her featured projects (Redora, Foodiq, CipherChat, Cake-and-Chaos), technical skill set, ServiceNow and PwC credentials, and a working contact form — all wrapped in a dark, modern single-page experience with fullscreen section navigation, an interactive skill keyboard, and a light-theme option. Built with 100% free tools and no build step.

## Features
- **Fullscreen sections** — Hero, Skills, Projects, Certified, Contact with smooth wheel / touch / arrow-key navigation, scroll progress bar and scroll-hint mouse
- **Animated hero** — avatar with rotating rings + floating badges, entrance animations, live Hyderabad clock, visitor counter, stat cards (CGPA, projects, certifications, stack keys)
- **Interactive skill keyboard** — press physical **A–Z** (on the skills page) or click/tap the 3D keys; each key maps to a real skill with readout screen, mechanical click sounds, optional voice readout, discovered counter with confetti at 26/26, plus stack chips
- **Projects** — Redora, Foodiq, CipherChat, Cake-and-Chaos as text-only cards with hover glow, detail modal (tech chips + ✨ highlights) and Code links
- **Certified & trained** — 4 credentials: ServiceNow CAD + CSA (2025) and 2 PwC technical trainee tracks
- **Contact** — form that sends straight to inbox via Web3Forms (with automatic mail-app fallback so no message is ever lost), copy-email button, profile card with socials
- **Theme + cursor** — dark/light toggle with a fully restyled light theme, purple dot-and-ring custom cursor, loader screen, grid + glow + particle + circuit background with film-grain overlay
- **Shortcuts** — `1–5` jump sections · `←/→/↑/↓` move · `T` theme · `Esc` close

## Stack (all free)
- Plain **HTML / CSS / JS** — double-click `index.html` to open
- **Bootstrap 5 + Bootstrap Icons** (CDN)
- **Google Fonts** — Plus Jakarta Sans, JetBrains Mono, Space Grotesk
- **Web Speech API** — optional voice readout for the skill keyboard (no key needed)
- **Web Audio API** — mechanical keyboard click sounds (no mp3 needed)
- **Web3Forms** — free contact-form-to-email (key already installed)
- **canvas-confetti** (CDN) — celebration effects

## Sections
1. **Hero** — greeting, role, tagline, buttons (Resume, Work, GitHub, LinkedIn), status pills, stats
2. **Skills** — interactive A–Z keyboard + stack chips
3. **Projects** — 4 featured builds with detail modals
4. **Certified & trained** — 4 credentials
5. **Contact** — message form + profile card

## Run locally

- Or: `python -m http.server 8000` inside this folder → http://localhost:8000
